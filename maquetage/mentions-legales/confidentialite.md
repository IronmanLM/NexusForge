# Politique de confidentialité

> Texte provisoire de maquette — relu par un juriste avant production.

## Données collectées

- Compte : pseudo, courriel, mot de passe chiffré.
- Âge : date de naissance, uniquement pour adapter les protections des mineurs.
- Mineurs : courriel d’un parent ou responsable légal, distinct du compte.
- Conteurs : traces de validation (double authentification active).

## Finalités

Création et sécurisation du compte, validation par un administrateur,
notifications de service. Aucune revente, aucune publicité.

## Conservation

Données supprimées avec le compte, sauf obligations légales. Les journaux
techniques de sécurité sont conservés douze mois maximum.

## Droits

Accès, rectification, suppression : écrire aux administrateurs depuis la page
d’aide. Réponse sous un mois.

## Témoins techniques

Le seul stockage local est la préférence de langue (`nf-langue`), sans traceur.
